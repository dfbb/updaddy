# updaddy macOS Smoke Checklist

适用范围：最新 macOS Apple Silicon，使用真实全局环境前先准备可回滚的测试包。除非测试项明确要求，避免对系统 Ruby、系统 Python 或生产 Homebrew 环境执行卸载。

## 生命周期和状态栏

- [ ] 启动应用后状态栏图标出现；模板图标在浅色和深色菜单栏中都清晰可见。
- [ ] 状态栏“可更新数量”显示所有可见生态的合计数量；点击数量项会打开概览。
- [ ] 状态栏菜单可执行一键更新、打开主窗口、打开设置和退出。
- [ ] 关闭主窗口后窗口隐藏，状态栏、计划任务和后台 worker 继续运行。
- [ ] 从状态栏退出后，正在运行的子进程被终止，任务最终状态和日志已写入数据库。
- [ ] 普通启动会显示主窗口；使用 `--autostart` 启动时仅驻留状态栏，不自动打开主窗口。
- [ ] 开机启动开关能注册和撤销 macOS 登录项；登录项会附带 `--autostart` 参数。

## 扫描、更新和卸载

- [ ] Homebrew、npm、pip、RubyGems、rustup 分别显示独立 tab；只管理全局安装资源。
- [ ] 检测不到包管理工具时，对应生态默认隐藏；隐藏生态不执行完整扫描、磁盘测量或计划更新。
- [ ] 应用重启时隐藏生态仍执行轻量 detect，但不会扫描包列表。
- [ ] 列表默认把待更新包放在前面；磁盘占用排序会对整个列表排序，并可切换升序/降序。
- [ ] 待更新包有单独更新按钮；每个包都有卸载按钮；卸载前显示二次确认且确认前不执行命令。
- [ ] 不同生态任务可以并行，同一生态任务串行。
- [ ] 任务运行期间扫描、更新、卸载、一键更新和刷新按钮均置灰；当前生态顶部的取消按钮仍可点击。
- [ ] 取消运行中的任务后，子进程结束，已完成包不回滚，未开始或当前任务显示已取消。

## 代理

- [ ] 直连模式下任务不注入代理环境变量。
- [ ] SOCKS5 模式支持地址、可选用户名和密码；认证失败不会静默回退直连。
- [ ] npm、pip、Gem、Homebrew 等 HTTP-only 工具使用内置 HTTP-to-SOCKS5 bridge。
- [ ] bridge 只监听 `127.0.0.1` 的随机端口，并要求每次启动生成的随机 Basic 代理凭据；无凭据或凭据错误时返回 HTTP 407。
- [ ] 使用 `lsof -nP -iTCP -sTCP:LISTEN` 检查 bridge，不应出现局域网监听地址。
- [ ] 代理断连、网络超时和 HTTP 5xx 按 5/30/120 秒退避；参数、权限、工具缺失和版本冲突不自动重试。
- [ ] 日志、状态栏和任务错误中不出现代理密码、Basic 凭据、Bearer token 或认证 URL。

## 计划、睡眠和恢复

- [ ] 设置页可保存每日或每周固定时间；关闭计划后不再创建计划批次。
- [ ] 让 Mac 在计划时间前睡眠，唤醒后只补执行当前周期一次；重复唤醒不会重复创建批次。
- [ ] 手动批次运行时到达计划时间，不创建重复批次。
- [ ] 强制结束并重启应用后，之前处于运行中的任务显示“已中断”，不会自动重复更新。
- [ ] 重启后历史、最近扫描快照和磁盘占用缓存可恢复。

## 主题、语言和日志

- [ ] 跟随系统、浅色、深色三种主题均能正确切换。
- [ ] 英文和简体中文资源来自 `lang/en.yaml`、`lang/zh_CN.yaml`；缺失键回退英文。
- [ ] 历史页可按生态和状态筛选；失败或中断任务可重新扫描后手动重试。
- [ ] 日志页以纯文本显示输出，不执行 HTML；可调整日志级别和完整命令输出保留开关。
- [ ] 启动或手动清理会删除 90 天以前的日志、批次和尝试记录，但保留设置、包快照和仍被引用的缓存。

## 自动构建验证

- [x] `cargo check --manifest-path src-tauri/Cargo.toml --target aarch64-apple-darwin` 通过。
- [x] `npx tauri build --target aarch64-apple-darwin --bundles dmg --ci` 通过。
- [x] `hdiutil verify` 确认 DMG 校验和有效；镜像内应用可执行文件为 arm64。
- [x] DMG 产物生成于 `src-tauri/target/aarch64-apple-darwin/release/bundle/dmg/updaddy_0.1.0_aarch64.dmg`。

常规 DMG 构建会调用 Finder AppleScript 美化磁盘镜像；在无可交互 Finder 的自动化环境中可能报 `-10006`。`--ci` 会跳过该装饰步骤，不影响应用编译、签名准备或 DMG 内容生成。

当前构建没有配置 Apple Developer ID，镜像内 `.app` 只有工具链生成的 ad-hoc 签名，尚未执行 Developer ID 签名和 Apple notarization。正式对外发布前必须补做签名、公证和 Gatekeeper 验证。
